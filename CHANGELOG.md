# Changelog

All notable changes to this project are documented here. The project follows semantic versioning.

## [0.1.0] - 2026-07-24

- Extract the production weighted graph-structured stack with leveled sharing from GLRMask.
- Expose persistent GSS, virtual-stack, weight-join, and structural-summary APIs.
- Add conventional standalone `popn` underflow semantics.
- Add typed Python 3.8+ bindings built with PyO3 and maturin.
- Add randomized model-equivalence tests, compressed-DAG tests, dual-backend tests, and cross-platform CI.
